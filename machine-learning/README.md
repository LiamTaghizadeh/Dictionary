# 🤖 واژه‌نامه جامع یادگیری ماشین

## نمای کلی

این ابزار تعاملی، یک مرجع کامل و بصری برای مفاهیم، مدل‌ها و الگوریتم‌های اساسی یادگیری ماشین است. با استفاده از HTML، CSS و جاوااسکریپت خالص ساخته شده و روشی شهودی برای کاوش اصطلاحات تخصصی این حوزه فراهم می‌کند. این پروژه شامل بیش از **۷۰ واژه‌ی کلیدی** است که هر کدام با کلیک روی کارت مربوطه، اطلاعات کاملی شامل **تعریف دقیق** و **تلفظ IPA (آوایی)** را نمایش می‌دهند[reference:0].

## ✨ ویژگی‌های کلیدی

### جستجوی هوشمند و ناوبری

| ویژگی | توضیح |
|---|---|
| **جستجوی بی‌درنگ** | با هر بار تایپ، واژه‌ها در لحظه فیلتر می‌شوند |
| **ناوبری الفبایی** | با کلیک روی هر حرف، به گروه واژگان مربوطه بروید |
| **نمایش همه واژه‌ها** | کل مجموعه را به‌صورت یکجا مرور کنید |
| **برجسته‌سازی جستجو** | عبارت‌های جستجو‌شده با رنگ لیمویی برجسته می‌شوند |
| **شمارنده زنده** | تعداد واژه‌های فیلتر شده نسبت به کل را نشان می‌دهد |
| **میانبرهای صفحه‌کلید** | `Ctrl+F` برای فوکوس روی جستجو و `Escape` برای پاک‌سازی فیلتر |

## 📖 ساختار اطلاعات هر واژه

با کلیک روی هر کارت، یک پنجره (Modal) باز می‌شود که شامل بخش‌های زیر است:

### ۱. واژه (انگلیسی)
نام دقیق اصطلاح به زبان انگلیسی.

### ۲. تلفظ (IPA)
تلفظ استاندارد آوایی (International Phonetic Alphabet) برای تلفظ صحیح واژه.

### ۳. تعریف
توضیح مفهومی و دقیق از اصطلاح، به همراه مثال‌های کاربردی.

## 🚀 نحوه استفاده

1.  **مرور کلی**: در صفحه اصلی، لیستی از تمام واژه‌ها به صورت کارت‌های خلاصه نمایش داده می‌شود.
2.  **جستجو**: از نوار جستجو برای پیدا کردن سریع یک واژه‌ی خاص استفاده کنید. جستجو بر اساس واژه‌ی انگلیسی و تعریف انجام می‌شود.
3.  **فیلتر**: با کلیک روی حروف الفبا در نوار سمت راست، می‌توانید واژه‌ها را بر اساس حرف اول فیلتر کنید.
4.  **مشاهده جزئیات**: روی هر کارت کلیک کنید تا پنجره‌ای با اطلاعات کامل آن واژه (تعریف و تلفظ) باز شود.
