# 📚 مرجع کامل الگوریتم‌های مرتب‌سازی

## نمای کلی

این ابزار تعاملی، مرجعی جامع و بصری برای آشنایی با الگوریتم‌های مرتب‌سازی است. با استفاده از HTML، CSS و جاوااسکریپت خالص ساخته شده و روشی شهودی برای کاوش مفاهیم، تاریخچه و پیاده‌سازی الگوریتم‌ها فراهم می‌کند. این پروژه شامل ۱۲ الگوریتم معروف است که هر کدام با کلیک روی کارت مربوطه، اطلاعات کاملی شامل تعریف، تلفظ، تاریخچه، مخترع، کد پایتون، مثال و تحلیل پیچیدگی زمانی را نمایش می‌دهند.

## 📖 ساختار اطلاعات هر الگوریتم

با کلیک روی هر کارت، یک پنجره (Modal) باز می‌شود که شامل بخش‌های زیر است:

### ۱. تعریف
توضیح مفهومی و ساده از الگوریتم و نحوه عملکرد آن.

### ۲. تاریخچه و مخترع
- **نام مخترع یا مخترعان**
- **سال معرفی**
- **داستان شکل‌گیری و نکات تاریخی**

### ۳. پیاده‌سازی در پایتون
کد تمیز و آماده‌ی اجرا به همراه توضیحات درون خطی (comments) برای درک بهتر.

### ۴. مثال عملی
یک آرایه‌ی نمونه به همراه خروجی مرتب‌شده برای درک بصری عملکرد الگوریتم.

### ۵. تحلیل زمان اجرا
جدولی شامل پیچیدگی زمانی در سه حالت:
- **بهترین حالت (Best Case)**
- **متوسط (Average Case)**
- **بدترین حالت (Worst Case)**

## 🚀 نحوه استفاده

1.  **مرور کلی**: در صفحه اصلی، لیستی از تمام الگوریتم‌ها به صورت کارت‌های خلاصه نمایش داده می‌شود.
2.  **جستجو**: از نوار جستجو برای پیدا کردن سریع یک الگوریتم خاص استفاده کنید. جستجو بر اساس نام فارسی، نام انگلیسی، تعریف، مخترع و حتی کد پایتون انجام می‌شود.
3.  **فیلتر**: با کلیک روی اعداد در نوار سمت راست، می‌توانید الگوریتم‌ها را بر اساس شماره فیلتر کنید.
4.  **مشاهده جزئیات**: روی هر کارت کلیک کنید تا پنجره‌ای با اطلاعات کامل آن الگوریتم باز شود.

## 🛠️ تکنولوژی‌های استفاده‌شده

- **HTML5**: ساختار صفحات
- **CSS3**: طراحی واکنش‌گرا (Responsive) و مدرن با تم تیره (Dark Theme)
- **JavaScript (Vanilla)**: تمام منطق برنامه، از جمله جستجوی بی‌درنگ، فیلتر، نمایش مودال و مدیریت وضعیت (State Management)
